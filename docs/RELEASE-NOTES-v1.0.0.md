# 🎨 dsh-free-skins v1.0.0 —— 人人有免费皮肤，自定义皮肤界面

DeepSeek Harness 界面皮肤插件首个公开版本，由 **0928OYX** 原创制作。

> **只做呈现，不碰模型**：所有皮肤只改变浏览器 DOM 与样式，不影响任何模型请求与数据安全。

## ✨ 功能亮点

- **界面皮肤画廊**：设置 → 界面皮肤，卡片式管理，先「试穿」后「应用」，一键切换零门槛。
- **一键应用，无需重启**：桌面端现场挂载即时生效；CLI 表面自动热重载；每次打开页面自动恢复已应用皮肤。
- **皮肤不透明度**：0-100% 滑块 —— 100% 为原图，50% 半透明，0% 全透明，每一档实时生效。
- **自定义对话区背景**：选择本机任意图片作为对话区壁纸，**固定不随对话滚动**；支持按对话区画幅「框选裁剪」，适配不同屏幕；自动保存。
- **右键输入菜单**：输入框支持右键 粘贴/复制/剪切/全选（桌面端原生右键菜单被禁用时的替代方案）。

## 🧑‍💻 给开发者

- 皮肤 = 一个 `definition.mjs`：配色、背景、粒子、角落装饰全部声明式定义，`scripts/generate-skins.mjs` 一键生成完整皮肤包 —— **做新皮肤只需 1 个文件 + 1 条命令**。
- 插件采用零构建依赖的手写 bundle（`skin-gallery/lib/client.js`），可直接阅读、修改、借鉴。
- 全部代码以 CC BY-NC-SA 4.0 开源，欢迎 fork、二次创作与 PR。

## 📦 安装

```sh
git clone https://github.com/0928OYX/dash-free-skins-Owner-0928OYX
cd dsh-free-skins
node scripts/deploy.mjs desktop
```
